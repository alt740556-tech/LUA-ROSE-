How to Use

1. Start the server

cd lua-key-system
npm install
npm start

Then open http://localhost:3000

2. Create a Script

  • Go to Scripts → New Script
  • Choose Protected (needs key + HWID) or Public
  • Paste your full Lua code and save

3. Create a Key (for protected scripts)

  • Go to Keys & HWID → Generate Key
  • Copy the key and give it to the user

4. Give the user the loader

For a protected script the user runs:

_G.script_key = "KEY-XXXX-XXXX-XXXX"
loadstring(game:HttpGet("http://YOUR_IP:3000/loader/protected/SCRIPT_ID"))()

For a public script:

loadstring(game:HttpGet("http://YOUR_IP:3000/loader/public/SCRIPT_ID"))()

5. Reset HWID

  • In the Keys table click Reset HWID
  • The next device that uses that key will bind to it

Notes

  • Replace YOUR_IP with your public IP or domain if hosting online.
  • Data is stored in data/keys.json and data/scripts/
  • This is a real server-side HWID lock – the check happens on your server.
